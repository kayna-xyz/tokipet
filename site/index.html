          Does it spend my tokens?
          
No. It passively reads the transcript files Claude Code already writes to ~/.claude/projects. No API calls, ever — zero tokens, zero dollars.

        

        

          Does my code go anywhere?
          
Nothing leaves your machine. One local state file (~/.tokipet/state.json), no accounts, no network.

          How is the token count calculated?
          
Input + output + cache reads + cache writes, summed from the day you installed. Cumulative for life — a new terminal never resets it.

        

        

          How do badges work?
          
They track grind hours — time actively burning tokens (gaps over 5 minutes don't count). Tiers at 1h / 22h / 44h / 88h / 8888h, each with a fixed gift: cow, spider, seal, Saturn, apple core.

        

        

          How do I switch pets, scenes, or languages?
          
Type /CLIadd in Claude Code — press 1–6 to adopt or toggle, 4 to cycle languages. The bar updates within a second.

        

        

          My pet is asleep. Is it okay?
          
It lies down after ~30 quiet minutes and wakes at your next burn. You can also order a nap: /talktopet go sleep.

        

        

          Can I uninstall it cleanly?
          
pet setup --remove (restores your Claude Code config), then npm uninstall -g tokipet. Delete ~/.tokipet if you want its memory gone too. It won't haunt your status bar. It might haunt you.
